# 🛰️ ShopVPN Amir

فورک شخصی و **مستقل** از [ShopVPN](https://github.com/mehdirafatpanah/Shopvpn) برای فروش و مدیریت سرویس‌های VPN و SSH از طریق تلگرام.

- **مخزن:** <https://github.com/amir12120/shopvpn-amir>
- **شاخه‌ی اصلی:** `main`
- **زبان رابط کاربری:** فقط فارسی و انگلیسی
- **نصب:** سبک، با خروجی انگلیسی و بدون LibreTranslate سنگین

> این مخزن دیگر فورک گیت‌هاب نیست و تاریخچه و ریلیزهای خودش را دارد. تغییرات
> پروژه‌ی مادر به‌صورت دستی و طبق [`SYNC_UPSTREAM.md`](SYNC_UPSTREAM.md) بررسی
> و اضافه می‌شوند.

---

## ✨ تفاوت‌های این فورک

| بخش | رفتار این فورک |
|---|---|
| زبان | فقط `fa` و `en`؛ زبان سوم نصب یا پیشنهاد نمی‌شود |
| ترجمه | مدل محلی Argos برای فارسی/انگلیسی؛ LibreTranslate فقط با انتخاب صریح |
| دیسک | بدون کش pip، PyTorch نسخه‌ی CPU، سقف حجم ژورنال و پاک‌سازی خودکار بعد از نصب و آپدیت |
| نصب | یک فرمان، خروجی انگلیسی، فقط توکن بات/آیدی ادمین و انتخاب Polling یا Webhook |
| آپدیت | `sp update` یا گزینه‌ی ۲ منو: دریافت کد، پکیج‌ها، ترجمه، پاک‌سازی، ری‌استارت و بررسی واقعی آماده‌بودن |
| خطای آپدیت | شکست به‌روزرسانی ترجمه فقط هشدار است و بات را از کار نمی‌اندازد |
| تعمیر ترجمه | نبود `SHOPVPN_TRANSLATION_LANGS` خودکار ساخته می‌شود و اسکریپت دیگر بی‌صدا خارج نمی‌شود |
| مخزن | از نسخه‌ی 4.17.0 مستقل شده؛ همگام‌سازی با سورس همچنان ممکن است |

## 🚀 نصب

روی سرور تازه‌ی Ubuntu 20.04+ یا Debian 11+ (Ubuntu 22.04 پیشنهاد می‌شود):

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/amir12120/shopvpn-amir/main/install.sh)
```

نصب‌کننده:

1. بسته‌های سیستمی لازم را نصب می‌کند،
2. مخزن را دریافت و محیط پایتون را می‌سازد،
3. پکیج‌ها و مدل‌های ترجمه‌ی فارسی/انگلیسی را نصب می‌کند،
4. توکن بات و آیدی عددی ادمین را می‌پرسد،
5. سرویس `v2raybot` را می‌سازد و اجرا می‌کند،
6. فرمان‌های `shopvpn` و `sp` را نصب می‌کند و منوی مدیریت را باز می‌کند.

راهنمای کامل، پیش‌نیازها و رفع اشکال: [`INSTALL.fa.md`](INSTALL.fa.md).

> در نصب مجدد، فایل `.env` و دیتابیس دست‌نخورده می‌مانند. همین فرمان، مسیر
> رسمی آپدیت هم هست.

## 🧰 مدیریت و آپدیت

```bash
shopvpn          # منوی تعاملی مدیریت
sp update        # دریافت کد، پکیج‌ها، ترجمه، پاک‌سازی، ری‌استارت و بررسی آماده‌بودن
sp status        # وضعیت سرویس‌ها و نسخه‌ی نصب‌شده
sp restart       # ری‌استارت و صبر تا بالا آمدن واقعی بات
sp version       # نمایش نسخه
```

سرویس بات یک واحد عادی systemd است:

```bash
sudo systemctl status v2raybot
sudo journalctl -u v2raybot -f
sudo systemctl restart v2raybot
```

اگر در پایان آپدیت پیام **«⚠️ Bot did not start»** دیدید، اول وضعیت واقعی سرویس را
بررسی کنید:

```bash
sudo systemctl status v2raybot --no-pager
sudo journalctl -u v2raybot -n 80 --no-pager
```

اگر مراحل بالا موفق بوده‌اند و فقط هشدار ترجمه دیده می‌شود، بات در حال اجراست.
خلاصه‌ی آپدیت فقط وقتی پیام خطای راه‌اندازی می‌دهد که سرویس واقعاً غیرفعال باشد.

## 🔌 فروش و تحویل سرویس

- تحویل خودکار کانفیگ روی پنل‌های پشتیبانی‌شده.
- **مدیریت SSH** (از نسخه‌ی 4.17): نودها، حساب‌ها، ساخت/تمدید/غیرفعال‌سازی، مصرف و لینک اشتراک SSH.
- **محصول ترکیبی VPN + SSH** با یک استخر حجم و انقضای مشترک؛ تمدید هر عضو، کل استخر را تمدید می‌کند.
- همگام‌سازی حجم باقی‌مانده روی پنل بعد از فروش و تمدید.
- موجودی کانفیگ، اتصال مستقیم محصول به پنل، خرید چندتایی و پلن‌های آزمایشی.
- تمدید زمانی/حجمی، سرویس‌های on-hold، جابه‌جایی سرویس و سقف ظرفیت پنل.
- مدیریت محصول/دسته، هشدار موجودی، کد تخفیف، کیف پول، کش‌بک، گیفت‌کارت و سکه.

## 💳 پرداخت و مشتری

- چند درگاه پرداخت خودکار، کارت‌به‌کارت، شارژ کیف پول و تأیید ادمین.
- بررسی رسید دستی: تکراری/OCR/فارنزیک، استعلام بانکی اختیاری؛ تصمیم نهایی با ادمین.
- تیکت پشتیبانی، چت زنده، عضویت اجباری کانال، ضداسپم و مسدودسازی کاربر.
- بات‌های نمایندگی، حالت نمایندگی متصل، سطح‌بندی، سقف اعتبار و پورسانت بازاریابی.

## 🖥️ رابط‌ها

- **پنل مدیریت تلگرام:** کاربران، محصولات، پنل‌ها، پرداخت‌ها، بکاپ، گزارش‌ها، ارسال همگانی و تنظیمات.
- **مینی‌اپ تلگرام:** فروشگاه، سفارش‌ها، سرویس‌ها، تمدید، SSH و پشتیبانی.
- **پنل مدیریت وب مستقل** (`admin_panel/`): رابط داده‌محور، نقش‌ها، تنظیمات و گزارش‌ها.
- **اپ اندروید مدیریت:** صفحات داده‌محور و اعلان Push.
- **API یکپارچه‌سازی:** دسترسی توکن‌محور برای ابزارهای بیرونی.

## 🧠 خودکارسازی و عملیات

- دستیار پشتیبانی هوش مصنوعی با اقدام‌های حساب و تحلیل تصویر/OCR چندمدلی.
- راهنمای هوشمند ادمین، کمپین‌ساز، پیش‌بینی ریزش و آموزش‌های متصل به بخش‌ها.
- بکاپ روزانه خودکار، بازیابی، مقصد دوم بکاپ و بازنشانی کارخانه‌ای.
- پایش سلامت پنل، گزارش‌های موضوعی، ارسال زمان‌بندی‌شده و ردیابی لینک تبلیغاتی.
- داشبورد ترجمه محلی، کنترل کیفیت و انتخاب زبان هر کاربر (فارسی/انگلیسی).

## 🖥️ پیش‌نیازها

- Ubuntu 20.04+ / Debian 11+ (Ubuntu 22.04 پیشنهاد می‌شود)
- Python 3.10+
- حداقل ۱ گیگ رم (۲ گیگ بهتر)
- حدود ۱.۵ گیگ فضای آزاد برای نصب سبک (بیشتر برای لاگ و بکاپ)
- توکن بات تلگرام و آیدی عددی ادمین
- دامنه با HTTPS برای وبهوک، مینی‌اپ یا پنل وب
- اطلاعات API درگاه‌های پرداخت و پنل‌های VPN فعال

> هرگز `.env`، توکن بات، کلید API یا دیتابیس عملیاتی را در گیت‌هاب قرار ندهید.
